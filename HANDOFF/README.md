## 快速事实

- **语言/栈**：TypeScript + Vite（Web）+ Capacitor（安卓/iOS）+ Electron（Windows）。无框架，纯 TS + DOM。
- **测试**：Vitest，**109 个测试全过**（`npm test`）。核心逻辑都有测试覆盖。
- **当前可编译**：`npx tsc --noEmit -p .` 干净，`npm run build` 通过。
- **品牌模块**：MINI、奔驰、宝马、捷豹路虎、大众集团（含奥迪）。丰田、通用 OBD 为占位。
- **没在真车上实测过**（开发环境没有车和 OBD 适配器）。诊断/记录接适配器应直接可用；解锁/刷写/调马力需要具体车型数据 + 真车验证。

## 给下一个 agent 的最重要三句话

1. **不要编造任何 seed/key 算法或 map 定义去糊弄"能用"**。没有就如实说没有、标 `unsupported`、让演示如实失败。这是这个项目的根本原则，见 `05-honesty-and-safety.md`。
2. **改 ECU 的功能必须有护栏**：范围钳制、人工确认、保留原厂备份、读回校验、不自动刷写。已经建好，别拆。
3. **真车相关功能没经过实车验证**，任何"已完成"都要带上这个前提。
